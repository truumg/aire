# AIRE — жилой дом в Хамовниках

Демонстрационный сайт премиального жилого дома: 48 квартир, панорамные окна,
терраса на крыше и двор без машин. Светлая «бумажная» тема с терракотовым
акцентом и тёмная тема-переключатель.

**Живая версия:** https://truumg.github.io/aire/

> Демонстрационный проект. Название, адрес, контакты и цены вымышлены,
> изображения используются как визуализации.

## Что внутри

- Адаптивная вёрстка без фреймворков и сборки.
- Переключение светлой и тёмной темы с сохранением выбора.
- Hero-блок, статистика со счётчиками, бегущая строка.
- Четыре типа квартир с планами в SVG.
- Секция 3D-плана с интерактивным наклоном.
- Галерея с лайтбоксом и управлением с клавиатуры.
- Схема локации в SVG, расстояния и ссылка на карты.
- Форма брони с валидацией, маской телефона и экраном успеха.
- Появление секций при прокрутке, прогресс чтения, мобильное меню.

## Структура

```
aire/
├── index.html      # разметка и контент
├── styles.css      # дизайн-система, темы, адаптив
├── script.js       # тема, меню, анимации, лайтбокс, форма
├── img/            # фотографии и 3D-план
└── README.md
```

## Локальный запуск

```bash
python -m http.server 4177
```

Откройте `http://localhost:4177/`.
